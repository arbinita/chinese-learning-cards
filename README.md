# Chinese Learning Cards App

An interactive and responsive flashcard-based web application designed to help users learn Chinese vocabulary through visual recognition, pronunciation, and contextual usage.

## Overview

This project provides a simple and intuitive learning experience using a "guess the word" approach. Users are presented with an image and prompted to identify the corresponding Chinese word before revealing the answer. The application emphasizes clarity, usability, and responsive design across devices.

## Features

- Image-based vocabulary learning
- Flip card interaction for revealing answers
- Chinese characters, pinyin, and English translations
- Audio pronunciation support
- Sentence examples for context
- Chapter-based navigation system
- Fully responsive design for mobile and desktop

## Technology Stack

- HTML5
- CSS3 (Flexbox, responsive design techniques)
- JavaScript (DOM manipulation and user interaction)

## Project Structure

- `index.html` – Main application structure
- `style.css` – Styling and responsive layout
- `script.js` – Application logic and data handling

## Usage

1. Open the application in a browser.
2. Select a chapter using the navigation buttons.
3. View the image and attempt to guess the word.
4. Tap the card to reveal the Chinese character, pronunciation, and meaning.
5. Use navigation buttons to move between words or chapters.
